# `/settings`

v0 ships exactly **one** live preference: hide/show balances, persisted server-side through
`identity.set_preferences`. Maps to design archive "Settings, SCREEN 09" — most of that screen's
rows (2FA, sessions, close account) are visible but inert in v0, not hidden.

This is the seed of the reversible-personalisation principle from the market brief: every UI
change a user can make, they can also undo.
